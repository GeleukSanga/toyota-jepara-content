# toyota-jepara-content

Repo konten PUBLIK untuk website Toyota Jepara.

- `data/*.json` — harga, promo, testimoni, poster, video, pengaturan, konten teks.
- `assets/*` — foto & video (disajikan via CDN jsDelivr).

Repo ini TIDAK berisi kode dan TIDAK terhubung ke deployment apapun. Token tulis admin hanya berlaku di repo ini, sehingga kebocoran token tidak bisa menyuntikkan kode ke website.
